# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What is Speckit?

Speckit is a Rust CLI for AI-native spec-driven development. It manages a structured workflow:

```
explore → propose → design → spec → tasks → apply → archive
```

All artifacts (proposals, designs, specs, tasks) are markdown files version-controlled alongside code. Speckit generates tool-specific skill files and slash commands for 38 AI tools (Claude Code, Cursor, Copilot, etc.).

## Build & Test Commands

```bash
cargo build --workspace --all-targets --all-features    # Build
cargo test --workspace --all-features                   # Run all tests
cargo test -p speckit-core                              # Run tests for one crate
cargo test -p speckit-core -- <test_name>               # Run a single test
cargo fmt --all -- --check                              # Check formatting
cargo clippy --workspace --all-targets --all-features -- -A warnings -A clippy::invalid_regex  # Lint
```

Release build: `cargo build --release` (LTO enabled, symbols stripped).

## Workspace Architecture

Four crates in a Cargo workspace:

| Crate | Role |
|-------|------|
| `speckit-cli` | Binary entry point (`src/main.rs`). CLI parsing via `clap` derive, dispatches to commands. |
| `speckit-core` | Core library (~154 files). Schemas, parsers, validation, store, templates, AI tool adapters, skill generation. |
| `speckit-commands` | Command implementations (~18 modules). Each CLI subcommand maps to a module here. |

**Dependency flow**: `cli` → `commands` → `core`.

## Key Modules in speckit-core

- `parsers/` — change_parser, code_fence parsing
- `schemas/` — workflow schema definitions (YAML-based)
- `templates/` — artifact templates and workflow text
- `store/` — store registry, metadata, git-backed storage
- `shared/` — tool detection, skill/command path resolution, generation
- `validation/` — structural validation of specs and changes
- `command_generation/adapters/` — per-AI-tool adapter generation
- `config.rs`, `global_config.rs`, `project_config.rs` — configuration layers
- `worksets.rs` — workset management
- `artifact_graph/` — artifact dependency graph

## Commands Crate Structure

Each module in `speckit-commands/src/` corresponds to a CLI subcommand: `init`, `change`, `spec`, `archive`, `validate`, `view`, `show`, `config`, `store`, `doctor`, `context`, `completion`, `workflow`, `workset`, etc. Shared logic lives in `shared_gather.rs` and `shared_output.rs`.

## Conventions

- Rust edition 2024
- Async runtime: tokio
- Error handling: `thiserror` for library errors, `anyhow` in the CLI layer
- Serialization: `serde` with `serde_yaml` (specs/schemas) and `serde_json` (programmatic output)
- CLI parsing: `clap` derive macros
- Most commands support `--json` output for agent consumption

## Speckit's Own AI Integration

The `.claude/` directory (gitignored, local-only) contains:
- `commands/opsx/` — slash commands: `apply`, `archive`, `explore`, `propose`, `sync`, `update`
- `skills/` — 6 skill directories, each with a `SKILL.md`

These are generated by `speckit init` and are the primary way Claude Code interacts with Speckit workflows.
