# Speckit CLI

Speckit manages specifications, change proposals, and implementation tasks.

The installed binary is the authority for command syntax:

    speckit --help
    speckit <command> --help

Use explicit `--help` for discovery; incomplete commands may execute.
Prefer `--json` where supported. Read identifiers and paths from output.
Preserve the selected `--store <id>` on commands that support it.

This skill explains CLI usage; it does not replace workflow instructions.
